# 🎮 Simon Game

A browser-based **Simon Says memory game** built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly long sequence of colors.

## 🚀 Features

- 🎯 Random color sequence generation
- 🧠 Increasing difficulty with each level
- 🖱️ Interactive button clicks
- ✨ Visual feedback for game and user actions
- 🏆 Highest score tracking
- 🔄 Game restart functionality
- 📱 Simple and responsive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Play

1. Open `index.html` in your web browser.
2. Press any key to start the game.
3. Watch the color sequence carefully.
4. Click the buttons in the same order.
5. Each successful round increases the level and adds another color to the sequence.
6. If you make a mistake, the game ends.
7. Try to beat your highest score!
